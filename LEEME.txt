AVO PAK S.A.S. — Control de Acceso de Personas y Vehículos (versión 2.0.0)
Dirección de Seguridad Integral

Contenido de esta carpeta
  index.html, js/, css/, img/, sw.js, manifest.webmanifest  -> la aplicación (no modificar)
  config.js   -> ÚNICO archivo a editar: bloque de conexión con Firebase, teléfonos, duración
                 máxima del turno, vigencia del PIN temporal y datos del responsable del tratamiento.
  textos.js   -> aviso de privacidad y textos legales (revisar con el responsable de
                 protección de datos antes de operar).

Funcionamiento (versión 2.0.0)
  - Base de datos e inicio de sesión: Firebase (Google), plan gratuito. Ya no se usa Microsoft 365.
  - Todos, incluido el administrador, ingresan SOLO con usuario y contraseña o PIN. Nadie usa correo.
  - El administrador crea, edita, restablece y da de baja usuarios en Consola > Usuarios.
    Roles: Administrador, Analista, Supervisor y Vigilante.
  - Cada vigilante o supervisor ingresa desde su propio celular; al ingresar se abre su turno y al
    cerrar el turno se cierra la sesión. El primer ingreso se hace con un PIN temporal (vence en 72 h)
    y la aplicación obliga a definir un PIN personal que nadie más conoce.
  - Los registros se guardan en el celular si no hay internet y se envían solos al volver la señal.
  - Las reglas de seguridad del servidor (archivo firestore.rules, que NO va en GitHub) impiden
    modificar o borrar registros, falsificar la hora o el autor, y que un vigilante vea usuarios,
    bitácora o cree personas. Dar de baja o restablecer el PIN corta de inmediato la sesión anterior.

Pasos de instalación (resumen)
  1. Crear una cuenta de Google con el correo corporativo del Director de Seguridad Integral.
  2. En console.firebase.google.com: crear el proyecto; activar Authentication > Correo
     electrónico/contraseña; agregar el dominio d-mazoavo.github.io en dominios autorizados.
  3. Crear Firestore Database (ubicación en Estados Unidos, modo producción) y publicar en la
     pestaña Reglas el contenido de firestore.rules.
  4. Registrar una app web en Configuración del proyecto y copiar el bloque firebaseConfig
     en config.js (reemplazando el bloque marcado).
  5. Subir esta carpeta a GitHub Pages.
  6. Abrir la dirección publicada: aparece "Instalación inicial". Escribir el código de
     instalación (está en firestore.rules) y crear el usuario administrador.
  7. Consola > Usuarios: crear vigilantes, supervisores y analistas (el PIN temporal se muestra
     una sola vez).
  8. Piloto de 4 semanas en paralelo con la planilla AP-SG-FT-001.

Cuota gratuita de Firebase (plan Spark; verificar valores vigentes en firebase.google.com/pricing)
  La aplicación descarga solo lo que cambió: una sincronización sin cambios consume 2 lecturas.
  Las fotografías de inspección se guardan reducidas (máximo ~600 KB cada una) con su huella SHA-256.
